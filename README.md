# HivePostify

This is the HivePostify account on GitHub. HivePostify is a Pakistan-built Web3 social and freelancing platform at [hivepostify.com](https://hivepostify.com), where creators and freelancers can publish, get hired and get paid with escrow protection.

The company overview, documentation and security policy live in the [HivePostifyPk organization](https://github.com/HivePostifyPk).

## What the platform does

- **Social publishing:** posts, feeds and communities for writers and creators
- **Freelance marketplace:** gigs, jobs and proposals
- **Escrow invoicing:** invoice links where the client's payment is held until the work is approved
- **Wallet and AHPT:** a Web3 wallet for every activated account, and the platform's native token
- **Messaging:** real-time chat between clients and freelancers

## How it's built

| Layer | Stack |
| :--- | :--- |
| Frontend | React 18, Tailwind CSS, Zustand, React Query, Framer Motion |
| Backend | Node.js, Express, MongoDB, Socket.io, JWT authentication |
| Web3 | Blockchain-based content permanence and rewards, plus the AHPT token |

## Quick answers

**What does it cost?** The platform fee is currently 3.7%. Listing gigs is free. Activation is a one-time fee with no renewals.

**Where are the docs?** In [hivepostify-docs](https://github.com/HivePostifyPk/hivepostify-docs).

**Who's behind it?** Aftab Irshad, a full-stack engineer in Punjab, Pakistan, founded it in 2025.

**Where do I get help?** [hivepostify.com/support](https://hivepostify.com/support).
